# Hópverkefni 1 

## Um verkefnið

Hópverkefni 1 í Vefforritun 1 gengur út á það að hanna vef út frá hönnun í Figma. 

Vefurinn inniheldur 3 síður: 

- **Forsíðu** `(index.html)`

- **Teymissíðu** `(teymi.html)`

- **Innskráningarsíðu** `(innskraning.html)`

--- 

## Kröfur og uppsetning
Til að keyra verkefnið þarf að hafa eftirfarandi uppsett: 

- Node.js
- npm

## Keyrsla 
Til að keyra Sass og Stylint, skrifaðu eftirfarandi skipanir í Terminal: 

```bash
npm install

npm run dev 

npm run lint 
```
